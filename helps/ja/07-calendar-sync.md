# 第7章 他のカレンダーと連携する

端末カレンダー連携を有効にすると、Android端末で利用できるカレンダーの予定をWorldCalendarに表示できます。端末カレンダーとの連携開始・同期には、カレンダーの読み取り・書き込みの両権限が必要です。予定の編集・作成には、対象カレンダー側の書き込み許可も必要です。

<a id="device-connect"></a>

## 連携を開始する

### 権限を許可する

1. メイン画面下部の<img class="button-icon" src="../../assets/icons/settings.svg" width="20" height="20" alt="歯車">（設定）をタップします。
2. 「予定の管理」をタップし、「アカウント連携」見出し右側の<img class="button-icon" src="../../assets/icons/link.svg" width="20" height="20" alt="鎖">（連携）をタップします。
3. 「同期する」をタップし、Androidの権限確認が表示されたらカレンダーの読み取り・書き込みの両権限を許可します。
4. 利用できるカレンダーの一覧が読み込まれたら、表示したいカレンダーを有効にします。

初回起動時の「外部カレンダー連携」からも設定できます。どちらかの権限がない場合、端末カレンダーとの連携開始・同期はできません。後から端末のアプリ権限設定で許可を変更できます。

### 表示するカレンダーを選ぶ

「予定の管理」の「アカウント連携」欄で、一覧にあるカレンダーごとに「☑／☐」（チェックボックス）で表示の有効・無効を切り替えます。無効にしたカレンダーの予定はメイン画面や検索結果から除外されます。カレンダーが一覧にない場合は、Android側にアカウントとカレンダーが登録されているか確認してください。

<a id="device-sync"></a>

## 同期を実行する

### 手動で同期する

「アカウント連携」が有効で、カレンダーの読み取り・書き込みの両権限が許可されていることを確認します。

「予定の管理」画面右上の<img class="button-icon" src="../../assets/icons/sync.svg" width="20" height="20" alt="2本の矢印が円を描く記号">（同期）をタップします。同期対象や通信・端末の状態によって、完了まで時間がかかる場合があります。端末カレンダーの同期は短時間に繰り返すと実行が保留されることがあります。

### 自動同期と反映のタイミング

アプリ起動時にも同期がスケジュールされます。端末カレンダーの更新は、直近の同期から5分以内の場合に省略されることがあります。変更直後に表示が変わらないときは、時間を置いてから手動同期してください。

<a id="device-permissions"></a>

## 権限と編集できる予定

### 編集・作成できる条件

端末カレンダー予定を編集できるのは、同期が有効で、対象カレンダーが書き込みを許可している場合です。新しい予定の保存先に端末カレンダーが表示されない場合は、連携・権限・書き込み可能なカレンダーの有無を確認してください。

### 連携を解除する

「予定の管理」の「アカウント連携」見出し右側の<img class="button-icon" src="../../assets/icons/link-off.svg" width="20" height="20" alt="斜線付きの鎖">（連携解除）をタップし、確認画面で「連携解除」を選びます。解除すると、アプリ内の連携カレンダーと取得済みの予定データが削除され、同期が停止します。購読カレンダー（iCal）の手動・自動更新も停止するため、更新を続ける場合はアカウント連携を有効にしてください。AndroidやGoogle側のカレンダーは削除されません。再度連携すると権限確認や読み込みが必要になる場合があります。
