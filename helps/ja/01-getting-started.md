# 第1章 はじめに

WorldCalendarは、グレゴリオ暦を含む複数の暦を切り替えて日付を見られるカレンダーアプリです。予定や設定は基本的に端末内に保存されます。端末カレンダーやiCalカレンダーを連携すると、それぞれの予定も表示できます。

このヘルプでは、文字のないボタンは「＋」（予定を追加）のように記号と機能名で案内します。文字で表しにくいボタンは、実際の形のアイコンを添えて説明します。

<a id="01-section-1"></a>

## 初回設定

### 利用する暦を選ぶ

初回起動後の案内で「始める」をタップします。「暦を選択」で使いたい暦のスイッチをオンにして「保存」をタップします。少なくとも1つの暦を有効にしてください。次の「表示順を設定」では、各行右端の「＝」を長押しして上下にドラッグし、暦の順番を決め、「次へ」をタップします。

### 端末カレンダー連携を選ぶ

「外部カレンダー連携」では、Android端末に登録されている予定を表示する連携を設定できます。連携する場合は画面の案内に従ってカレンダーの読み取り・書き込みの両権限を許可します。後から<img class="button-icon" src="../../assets/icons/settings.svg" width="20" height="20" alt="歯車">（設定）>「予定の管理」でも設定できます。詳しくは[端末カレンダーとの同期](07-calendar-sync.md)をご覧ください。

連携する場合は「同期する」、あとで設定する場合は「今はしない」を選びます。

<a id="01-section-2"></a>

## まず使ってみる

### 表示暦を切り替える

メイン画面左上の暦名と「▼」をタップし、表示する暦を選びます。有効にした暦が切り替え候補になります。候補を変更するには<img class="button-icon" src="../../assets/icons/settings.svg" width="20" height="20" alt="歯車">（設定）>「暦の表示設定」を開きます。

### 日付や予定を見る

月表示では日付をタップすると、その日の予定と祝日が開きます。予定をタップすると「予定詳細」を確認できます。月を移動するには左右にスワイプするか、画面上部の年月をタップして年月ピッカーを使います。

### 予定を追加する

メイン画面右下の「＋」（予定を追加）をタップし、タイトルや日時を入力して「保存」します。日付を先に選んでから追加すると、その日付が入力画面に設定されます。詳しくは[予定を作成・編集する](04-events.md)をご覧ください。

<a id="01-section-3"></a>

## オフラインでの利用

暦表示と端末内に保存した予定は、ネットワーク接続がなくても利用できます。iCal購読カレンダーの追加・更新には通信が必要です。端末カレンダーとの同期はAndroidのカレンダー機能と権限に依存します。同期の状態によっては、最新の予定が表示されるまで時間がかかることがあります。

| 操作 | 通信がないとき |
| --- | --- |
| 暦の切り替え、アプリ内予定の追加・編集・削除 | 利用できます |
| カテゴリ・テーマの設定 | 利用できます |
| 取得済みの連携・購読予定の表示 | 端末内に保存されている内容を確認できます |
| 公開カレンダーの新規取得・更新 | 通信が必要です。追加後の更新にはアカウント連携の有効化も必要です |
| 端末のアカウントとクラウド側の予定の更新 | Androidやアカウント側の通信・同期状態に依存します |
