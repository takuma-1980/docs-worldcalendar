# 第4章 予定を追加・編集する

予定はWorldCalendar内、Android端末のカレンダー、またはiCal購読カレンダーから表示できます。編集できる範囲は予定の保存先によって異なります。

<a id="event-save-target"></a>

## 予定の保存先

| 操作・機能 | アプリ内（ローカル） | 端末カレンダー（アカウント連携） | 公開カレンダー（購読・iCal） |
| --- | --- | --- | --- |
| 予定の表示 | 可能 | 連携と表示が有効な場合 | 購読と表示が有効な場合 |
| 新しい予定の保存 | 可能 | 連携・権限があり、書き込み可能な保存先がある場合 | 不可 |
| 編集・削除 | 可能 | 同期が有効で、カレンダーが書き込みを許可している場合 | 不可（読み取り専用） |
| 別の予定として複製 | 可能 | 可能 | 可能 |
| カテゴリ | 利用可能 | アプリ内カテゴリは利用不可 | アプリ内カテゴリは利用不可 |
| 通知 | 利用可能（最大5件） | 予定の通知設定と連携側の「予定の通知」スイッチによる | 購読予定への通知追加は不可 |
| 情報の更新 | アプリ内で保存 | 端末カレンダーとの同期 | 公開カレンダーの再取得（追加後の更新にはアカウント連携が必要） |

### 保存先の違い

- **アプリ内の予定（ローカル）**：WorldCalendarに保存します。カテゴリ、通知、繰り返しを利用できます。
- **端末カレンダー**：Androidに登録されているカレンダーへ保存します。利用には連携と権限が必要で、書き込み可能なカレンダーだけが候補になります。
- **購読カレンダー**：iCal URLから取得します。読み取り専用で、アプリから編集できません。

既存予定の詳細画面に<img class="button-icon" src="../../assets/icons/edit.svg" width="20" height="20" alt="鉛筆">（編集）がない場合、予定が読み取り専用か、保存先のカレンダーに編集権限がない可能性があります。同期の設定は[端末カレンダーとの同期](07-calendar-sync.md)を確認してください。

<a id="event-add"></a>

## 予定を追加する

### 入力して保存する

1. メイン画面右下の「＋」（予定を追加）をタップします。日付を選択してから追加した場合、その日付が入力欄に反映されます。
2. タイトルを入力します。必要に応じて説明、場所、終日、開始・終了日時を設定します。
3. 必要に応じて繰り返しや通知を設定します。ローカル予定にはカテゴリも設定できます。
4. 新規作成時は保存先を選びます。端末カレンダーは連携済みで、利用可能なカレンダーがある場合に表示されます。
5. 「保存」をタップします。

新規予定の時刻は、作成を始めた時刻を30分単位に切り上げた値が初期設定されます。保存先によって利用できる項目が変わります。アプリ内カテゴリはローカル予定だけに設定できます。購読予定には通知を追加できません。端末カレンダーの通知を使う場合は、[通知の設定](05-recurrence-notifications.md)を確認してください。

### 日時を入力する

開始日・終了日は、入力画面に表示されている暦を基準に入力します。終日の予定にする場合は「終日」をオンにします。日付選択画面の「‹」（前の月）・「›」（次の月）で月を移動できます。終了日時は予定の長さに合わせて確認してください。

<a id="event-edit-copy-delete"></a>

## 予定を編集・複製・削除する

### 予定を編集する

予定詳細を開き、<img class="button-icon" src="../../assets/icons/edit.svg" width="20" height="20" alt="鉛筆">（編集）をタップします。項目を変更して「保存」します。保存先は既存のものから変更できません。端末カレンダーの予定は、そのカレンダーが書き込み可能で同期が有効な場合に編集できます。

### 予定を複製する

読み取り専用の予定を含め、予定詳細の<img class="button-icon" src="../../assets/icons/content-copy.svg" width="20" height="20" alt="重なった2枚の紙">（複製）をタップします。複製用の入力画面が開き、新しいアプリ内予定として始まります。保存先を選べる場合は変更できます。内容や日時を確認し、「保存」すると元の予定とは別の予定になります。

### 予定を削除する

予定詳細の<img class="button-icon" src="../../assets/icons/delete.svg" width="20" height="20" alt="ごみ箱">（削除）をタップし、確認画面に従います。繰り返し予定では「この予定のみを削除」「これ以降の予定をすべて削除」「すべての予定を削除（過去分を含む）」から範囲を選び、「実行」をタップします。端末カレンダー上の繰り返し予定では、今回のみ・これ以降の削除が提供元へ反映されない場合があります。

<a id="event-source-and-editing"></a>

## 予定の情報と編集可否

### 予定の出所を確認する

購読予定の詳細には購読カレンダー名が表示されます。端末カレンダー予定の保存先は予定編集画面や「予定の管理」のカレンダー一覧で確認できます。購読予定は読み取り専用です。

### 編集できないとき

予定詳細に<img class="button-icon" src="../../assets/icons/edit.svg" width="20" height="20" alt="鉛筆">（編集）や<img class="button-icon" src="../../assets/icons/delete.svg" width="20" height="20" alt="ごみ箱">（削除）がない場合は、iCal購読予定か、端末側で書き込みが許可されていないカレンダーの予定です。端末カレンダーの場合は、[同期と権限](07-calendar-sync.md#device-permissions)を確認してください。
