# 第10章 バックアップと機種変更

WorldCalendarのユーザーデータはAndroidのバックアップ・端末移行機能で対象になる場合があります。ただし、実際にバックアップや復元が行われるかは、Androidのバージョン、端末メーカー、Googleアカウント、端末のバックアップ設定などに左右されます。アプリだけで復元を保証するものではありません。

<a id="10-section-1"></a>

## バックアップ対象

### 保存されるデータ

Androidのバックアップ対象には、アプリ内の予定、通知設定、繰り返しの例外、カテゴリ、暦設定、購読カレンダーの登録情報、および一部のユーザー設定が含まれます。Androidの自動バックアップまたは端末間データ移行が有効な場合、OSの仕組みを通じて保存されることがあります。

### 対象外のデータ

端末カレンダーとの紐付けや権限、カレンダー一覧の選択状態、取得済みの予定、購読カレンダーから取得した予定データ、同期状態、端末依存の通知スケジュール、ウィジェットの配置・表示設定は対象外です。一方、端末同期のオン・オフや端末カレンダー通知の設定値、テーマ・暦表示設定はユーザー設定としてバックアップに含まれる場合があります。復元後は実際の連携状態を確認し、必要に応じて再連携・同期してください。

<a id="10-section-2"></a>

## 機種変更の前後に確認する

### 移行前

1. Androidの設定で、Googleバックアップまたは端末のデータ移行が有効か確認します。
2. WorldCalendarを最新版にし、端末のバックアップが完了していることを確認します。
3. 重要な予定が移行後も必要なことを、予定の保存先（ローカル、端末カレンダー、購読カレンダー）ごとに確認します。

端末カレンダーの予定はAndroidアカウント側で管理されるため、そのアカウントの同期・移行状態も確認してください。購読予定は新しい端末でフィードを再同期して取得します。バックアップ条件は[Androidの自動バックアップ](https://developer.android.com/identity/data/autobackup)もご覧ください。

### 移行後

1. 新しい端末で同じGoogleアカウントを使い、Androidの復元を完了します。
2. WorldCalendarを起動し、予定や設定が復元されているか確認します。
3. Androidのカレンダーの読み取り・書き込みの両権限を許可し、<img class="button-icon" src="../../assets/icons/settings.svg" width="20" height="20" alt="歯車">（設定）>「予定の管理」から端末カレンダーを連携します。
4. 購読カレンダーの更新にも「アカウント連携」が有効であることが必要です。連携の状態と購読カレンダーの登録内容を確認し、「予定の管理」右上の<img class="button-icon" src="../../assets/icons/sync.svg" width="20" height="20" alt="2本の矢印が円を描く記号">（同期）をタップします。
5. 通知権限とホーム画面ウィジェットを再設定します。

<a id="10-section-3"></a>

## 復元で予定が見つからない場合

OSや端末メーカーがバックアップを実行しなかった場合、復元元とアプリのバージョンが異なる場合などは、予定や設定が戻らないことがあります。アプリのアンインストールやデータ消去の前に、必要な情報がAndroidのバックアップに含まれていることを確認してください。WorldCalendarにはアプリ内の一括エクスポート／インポート機能はありません。
