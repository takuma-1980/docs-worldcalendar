# 第8章 公開カレンダーを追加する

iCal（ICS）形式のURLを登録すると、公開カレンダーの予定をWorldCalendarに表示できます。画面上の名称は「購読（iCal）」です。購読カレンダーの予定は読み取り専用です。[保存先による操作の違い](04-events.md#event-save-target)も確認してください。

<a id="ical-add"></a>

## 購読カレンダーを追加する

### URLを登録する

1. <img class="button-icon" src="../../assets/icons/settings.svg" width="20" height="20" alt="歯車">（設定）>「予定の管理」を開きます。
2. 「購読（iCal）」見出し右側の「＋」をタップします。
3. 必要に応じてプリセットを選び、カレンダー名、URL、色を入力します。
4. 保存します。追加後にカレンダーの初回取得が始まります。

追加時の初回取得は「アカウント連携」が無効でも行われます。ただし、その後の手動・自動更新には「アカウント連携」の有効化が必要です。[更新の条件](#ical-sync)を確認してください。

利用できるプリセットは日本の祝日です。六曜は<img class="button-icon" src="../../assets/icons/settings.svg" width="20" height="20" alt="歯車">（設定）>「予定の管理」にある「六曜を表示」の「☑／☐」（チェックボックス）で切り替えます。URLを自分で入力する場合はHTTPSの公開ICS URLを使用してください。`webcal://` URLは保存時にHTTPSへ変換されます。重複URLは登録できません。安全のため、ユーザー名・パスワードを含むURL、localhostや`.local`のホスト、標準以外のポートは利用できません。

### URLの入手先を確認する

カレンダー提供元が案内する「iCal」「ICS」「秘密のアドレス」などの購読用URLを使います。ログインが必要なページのURLや、カレンダー画面そのもののURLでは読み込めません。URLには閲覧権限が含まれる場合があるため、共有範囲に注意してください。

<a id="ical-manage"></a>

## 購読を管理する

### 表示・色・内容を変更する

「予定の管理」の購読カレンダー一覧で、各行の「☑／☐」（チェックボックス）で表示を有効・無効にできます。無効にしたフィードの予定はメイン画面と検索結果に表示されません。行の<img class="button-icon" src="../../assets/icons/edit.svg" width="20" height="20" alt="鉛筆">（編集）で名前・URL・色を変更できます。登録上限は10件です。

<a id="ical-sync"></a>

### 同期状態を確認・更新する

現在のアプリでは、iCalの手動・自動更新にも「アカウント連携」が有効であることが必要です。無効な場合、手動・自動のどちらでも購読カレンダーは更新されません。先に「予定の管理」の「アカウント連携」から連携を開始してください。開始にはAndroidのカレンダーの読み取り・書き込みの両権限が必要です。手順は[他のカレンダーとの連携](07-calendar-sync.md#device-connect)をご覧ください。

一覧には最終同期の状態や時刻が表示されます。手動で更新するには「予定の管理」画面右上の<img class="button-icon" src="../../assets/icons/sync.svg" width="20" height="20" alt="2本の矢印が円を描く記号">（同期）を使います。自動同期はアプリ起動時にスケジュールされますが、自動同期では24時間以内に同期済みの購読カレンダーを省略します。手動同期には5分のクールダウンがあります。連続して同期を実行してもすぐ反映されない場合は、時間をおいて再試行してください。

### 購読カレンダーを削除する

対象行の<img class="button-icon" src="../../assets/icons/delete.svg" width="20" height="20" alt="ごみ箱">（削除）をタップします。削除するとそのフィードの予定は表示されなくなります。提供元のカレンダーやアカウント自体は削除されません。

<a id="ical-read-only"></a>

## 購読予定の編集について

購読カレンダーから取得した予定は読み取り専用です。ICS内の繰り返し予定の個別変更（RECURRENCE-ID）は読み込み対象外です。複雑な繰り返しや提供元固有の情報を含む予定は、すべてが再現されるとは限りません。予定詳細から編集・削除はできませんが、<img class="button-icon" src="../../assets/icons/content-copy.svg" width="20" height="20" alt="重なった2枚の紙">（複製）で別の予定として複製できます。コピーは新しいアプリ内予定として始まり、保存先を選べる場合は変更できます。元の購読予定を変更するには、提供元のカレンダーで編集してください。
