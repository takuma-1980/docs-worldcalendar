# 第2章 世界の暦を使う

WorldCalendarでは、日付表示の基準となる暦を切り替えられます。暦は日付の数え方や月の構成が異なるため、同じ日でも暦ごとに表示される年月日が変わります。

<a id="calendar-types"></a>

## 利用できる暦

### 6種類の暦

- **グレゴリオ暦**：一般的な西暦です。
- **旧暦（太陰太陽暦）**：月の満ち欠けと太陽年を組み合わせた暦です。日本など東アジアの歴史的な暦として知られます。
- **ユリウス暦**：グレゴリオ暦より前に広く使われた太陽暦で、現在も一部の教会暦などで用いられます。
- **ユダヤ暦**：月と太陽の周期を組み合わせた暦で、ユダヤ教の行事などに使われます。
- **インド太陰太陽暦（Amanta）**：インドの暦法の一つで、アマーンタ方式で表示します。日の数字は月初からの経過日数で、宗教暦のティティとは異なります。
- **エチオピア暦**：エチオピアなどで使われる13か月の暦です。

ヒンドゥー暦と旧暦の表示は、読み込みに少し時間がかかる場合があります。

<a id="calendar-limits"></a>

## 暦の日付と計算方法について

暦の日付はアプリの計算方式に基づいて表示します。暦法には地域・宗派・時刻帯による運用差があるため、特定の地域の公式日付や宗教上の判断と一致しない場合があります。インド太陰太陽暦はAmanta方式です。ヒンドゥー暦の月や日付は、地域ごとの慣習や天文計算の違いをすべて選び分ける機能ではありません。重要な行事の日付は、対象地域・団体の公式情報も確認してください。

### 日付が切り替わる時刻

アプリが日付の表示に使う基準は次のとおりです。

| 暦 | 日付表示の基準 |
| --- | --- |
| グレゴリオ暦・ユリウス暦 | 端末のタイムゾーンの午前0時 |
| 旧暦 | 日本時間の午前0時 |
| ユダヤ暦 | エルサレム時間の午前0時（日没による切り替えではありません） |
| インド太陰太陽暦（Amanta） | インド時間の午前0時（日の出や宗教暦のティティとは異なります） |
| エチオピア暦 | アディスアベバ時間の午前6時 |

エチオピア暦の時刻付き予定では、入力した00:00が端末タイムゾーンの06:00に相当します。日付表示と予定の時刻入力で基準が異なるため、端末のタイムゾーンや日付の境界付近では、予定の日時も確認してください。

### 計算の範囲と参考情報

年月選択で移動できる範囲は、すべての地域の暦や歴史上の日付との一致を保証する範囲ではありません。暦の方式や閏月の扱いによって日付が異なるため、年月日の数字だけで他の暦と比較しないでください。

暦の基本的な仕組みは[米国海軍天文台の暦の解説](https://aa.usno.navy.mil/faq/calendars)、グレゴリオ暦とユリウス暦の違いは[国立天文台の解説](https://eco.mtk.nao.ac.jp/koyomi/topics/html/topics1994.html)も参考になります。これらは一般的な暦の解説です。本アプリの計算精度を保証するものではありません。

<a id="calendar-switch"></a>

## 表示する暦を切り替える

### メイン画面で切り替える

メイン画面左上にある現在の暦名と「▼」をタップし、表示したい暦を選びます。選択できるのは有効にした暦です。日付の詳細には、選択中の暦の日付が表示されます。

### 有効・無効を変更する

1. メイン画面下部の<img class="button-icon" src="../../assets/icons/settings.svg" width="20" height="20" alt="歯車">（設定）をタップします。
2. 「暦の表示設定」をタップします。
3. 各暦のスイッチを切り替えます。

最低1つの暦を有効にする必要があります。初回設定の「暦を選択」でも同じ選択ができます。

<a id="calendar-order-color"></a>

## 表示順と色

### 暦の順番を変える

<img class="button-icon" src="../../assets/icons/settings.svg" width="20" height="20" alt="歯車">（設定）>「暦の表示設定」で暦の行の右端にある「＝」（並び替えハンドル）を長押しし、上下にドラッグします。ここでの順序は、メイン画面の暦切り替え候補にも反映されます。初回設定の「表示順を設定」でも並び替えられます。

### 暦の色を変える

<img class="button-icon" src="../../assets/icons/settings.svg" width="20" height="20" alt="歯車">（設定）>「暦の表示設定」で、対象の暦の行にある「●」（色の丸）をタップします。色の選択画面で色を選ぶと保存され、元の画面に戻ります。色は暦の表示を見分けるために使われます。画面に色選択がない暦や、このビルドで利用できない暦は変更できません。

<a id="rokuyo-settings"></a>

## 六曜

### 六曜を表示する

<img class="button-icon" src="../../assets/icons/settings.svg" width="20" height="20" alt="歯車">（設定）>「予定の管理」を開き、画面下部の「六曜を表示（グレゴリオ暦・旧暦のみ）」にある「☑／☐」（チェックボックス）をタップします。六曜はグレゴリオ暦または旧暦の表示に対応します。ほかの暦では表示されません。

六曜には先勝・友引・先負・仏滅・大安・赤口があります。表示は暦上の参考情報です。地域で採用される計算慣行や暦注の違いにより、他の資料と一致しない場合があります。
