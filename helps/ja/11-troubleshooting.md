# 第11章 困ったとき・よくある質問

症状に近い項目を確認してください。画面名が見つからない場合は、アプリを最新版に更新してから、メイン画面下部の<img class="button-icon" src="../../assets/icons/settings.svg" width="20" height="20" alt="歯車">（設定）をタップしてください。

<a id="11-section-1"></a>

## 暦や日付の表示

### 暦を切り替えられない

**原因：** 切り替え先の暦が無効、または利用できないビルドです。

**確認方法：** <img class="button-icon" src="../../assets/icons/settings.svg" width="20" height="20" alt="歯車">（設定）>「暦の表示設定」で対象のスイッチを確認します。「このビルドでは利用不可」と表示される暦は選択できません。

**解決方法：** 利用できる暦を有効にし、メイン画面左上の暦名から切り替えます。

### 日付が他のカレンダーと一致しない

**原因：** 暦法の方式、地域、時刻帯、宗教上の慣行が異なることがあります。

**確認方法：** 表示中の暦名と地域・宗教上の採用方式を確認します。

**解決方法：** [暦の種類と地域差](02-calendars.md#calendar-limits)を参照し、重要な行事の日付は該当地域・団体の公式情報で確認してください。

### 六曜が表示されない

**原因：** 六曜の表示設定がオフか、対応していない暦を表示しています。

**確認方法：** <img class="button-icon" src="../../assets/icons/settings.svg" width="20" height="20" alt="歯車">（設定）>「予定の管理」の「六曜を表示（グレゴリオ暦・旧暦のみ）」と、メイン画面で選択中の暦を確認します。

**解決方法：** 「☑／☐」（チェックボックス）をオンにして、グレゴリオ暦または旧暦を選びます。[六曜の設定](02-calendars.md#rokuyo-settings)をご覧ください。

### 祝日が表示されない

**原因：** 祝日カレンダーが未登録、非表示、またはまだ取得されていない可能性があります。

**確認方法：** 「予定の管理」の「購読（iCal）」で、祝日カレンダーの有無、「☑／☐」（チェックボックス）、同期結果を確認します。

**解決方法：** 日本の祝日は[日本の祝日プリセットを追加](08-subscriptions.md#ical-add)し、表示をオンにして同期します。すべての国の祝日が暦の切り替えだけで表示されるわけではありません。

### 暦の表示に時間がかかる

**原因：** 旧暦やヒンドゥー暦などの表示計算に時間がかかっている場合があります。

**確認方法：** 旧暦やヒンドゥー暦の表示中か確認します。

**解決方法：** 読み込みが終わるまで待ちます。画面を開き直しても続く場合は、アプリを再起動してください。

<a id="11-section-2"></a>

## 予定と通知

### 保存した予定がカレンダーに表示されない

**原因：** 表示対象のカテゴリ・カレンダーがオフ、表示中の月が違う、または繰り返し日がその暦・年に存在しない可能性があります。

**確認方法：** 保存先と予定の日付を確認し、「予定の管理」でカテゴリ、連携先、購読カレンダーの表示状態を調べます。対象期間内なら[予定検索](06-search-categories.md#search-events)も試します。

**解決方法：** 対象の表示をオンにして予定の月へ移動します。連携先の予定なら同期し、繰り返し予定なら[暦による日付の扱い](05-recurrence-notifications.md)も確認してください。

### 予定を編集・削除できない

**原因：** 購読カレンダーの予定は読み取り専用です。端末カレンダーの予定も、連携が無効か、カレンダー側が書き込みを許可していないと編集できません。

**確認方法：** 予定詳細に<img class="button-icon" src="../../assets/icons/edit.svg" width="20" height="20" alt="鉛筆">（編集）があるか確認します。端末カレンダー予定の場合は「予定の管理」のアカウント連携一覧も確認します。

**解決方法：** 端末カレンダーの場合は、[権限と編集条件](07-calendar-sync.md#device-permissions)を確認します。購読予定は<img class="button-icon" src="../../assets/icons/content-copy.svg" width="20" height="20" alt="重なった2枚の紙">（複製）から別予定として保存できます。

### 予定が検索結果に出ない

**原因：** 検索は現在日時の前後2年間が対象です。また、無効にした端末カレンダーや購読カレンダーの予定は検索されません。

**確認方法：** 対象日が前後2年以内か、対象の端末・購読カレンダーが有効か確認します。検索対象にはタイトル・説明・カテゴリ名・日付が含まれます。

**解決方法：** これらの項目に含まれる語で検索し直してください。

<a id="notification-missing"></a>

### 通知が届かない

**原因：** Androidの通知権限がオフ、ローカル予定に通知時刻がない、端末カレンダー通知がアプリ側でオフ、または端末の省電力設定が影響している可能性があります。

**確認方法：** Androidの設定でWorldCalendarの通知が許可されているか、ローカル予定に通知タイミングがあるか確認します。端末カレンダー予定では<img class="button-icon" src="../../assets/icons/settings.svg" width="20" height="20" alt="歯車">（設定）>「予定の管理」>「アカウント連携」の「予定の通知」も確認します。

**解決方法：** 通知を許可し、ローカル予定の通知時刻を設定するか、端末カレンダー予定の「予定の通知」をオンにします。端末カレンダー側でも通知が有効な場合は二重に届くことがあるため、どちらかの通知設定を調整してください。端末の省電力設定も確認してください。通知は端末状態により遅れることがあります。

### 通知が二重に届く

**原因：** WorldCalendarと他のカレンダーアプリの両方が、同じ連携予定を通知している可能性があります。

**確認方法：** 通知に表示されるアプリ名と、「予定の管理」の「アカウント連携」にある「予定の通知」を確認します。

**解決方法：** WorldCalendarからの連携予定通知が不要なら、そのスイッチをオフにします。他のアプリからの通知を止めたい場合は、該当アプリの通知設定を調整します。

<a id="device-calendar-missing"></a>

## 端末カレンダーが表示されない

### Googleカレンダーなどの一覧や予定が空のまま

**原因：** カレンダーの読み取り・書き込みのいずれかの権限がない、Androidに利用可能なカレンダーがない、対象カレンダーが無効、または同期がまだ完了していない場合があります。

**確認方法：** Androidのアプリ権限でカレンダーの読み取り・書き込みが両方許可されているかを確認し、連携の状態と対象カレンダーの「☑／☐」（チェックボックス）を確認します。

**解決方法：** 読み取り・書き込みの両権限を許可して連携を有効にし、対象カレンダーをオンにしてから手動同期します。短時間に同期済みの場合は少し待って再試行してください。

### 端末カレンダーへ保存できない

**原因：** 書き込み権限がない、または書き込み可能なカレンダーがありません。

**確認方法：** Androidのカレンダー権限と、端末側に書き込み可能なカレンダーがあるか確認します。

**解決方法：** 権限を許可するか、端末側で書き込み可能なカレンダーを用意します。使えない場合はローカル保存先を選びます。

<a id="ical-load-error"></a>

## iCalカレンダーを読み込めない

### URLを保存できない

**原因：** URLがHTTPSではない、URLが重複している、またはURLのホストやポートが利用条件に合っていない可能性があります。

**確認方法：** URLが提供元の購読用ICS URLか、重複登録でないか確認します。

**解決方法：** HTTPSまたは`webcal://`の購読URLを入力します。ログイン情報をURLに含めず、標準ポートの公開URLを使ってください。

### 保存できたが予定が表示されない

**原因：** 公開URLでない、サーバーが応答しない、ICS形式を読み取れない、または購読が無効になっている可能性があります。

**確認方法：** 購読カレンダーが有効か、最終同期状態、URLが現在も有効かに加え、「アカウント連携」が有効か確認します。

**解決方法：** 「アカウント連携」が無効なら、[連携を開始](07-calendar-sync.md#device-connect)してから「予定の管理」右上の<img class="button-icon" src="../../assets/icons/sync.svg" width="20" height="20" alt="2本の矢印が円を描く記号">（同期）を使います。更新直後は少し時間をおいて再試行してください。

### 追加できた購読カレンダーが、その後更新されない

**原因：** 「アカウント連携」が無効だと、iCalを含む手動・自動同期が行われません。追加時の初回取得だけは行われるため、追加直後は予定が表示されても、その後の変更が反映されないことがあります。

**確認方法：** 「予定の管理」で「アカウント連携」が有効か確認します。

**解決方法：** [アカウント連携を開始](07-calendar-sync.md#device-connect)し、カレンダーの読み取り・書き込みの両権限を許可してから同期します。連携が有効でも更新されない場合は、通信状態と[同期の間隔](08-subscriptions.md#ical-sync)も確認してください。

<a id="widget-not-updated"></a>

## ウィジェットが更新されない

### 表示日付が古い

**原因：** ホームアプリやAndroidの省電力機能が更新を遅らせている可能性があります。

**確認方法：** 端末の時刻とタイムゾーン、ホームアプリの省電力制限を確認します。

**解決方法：** ウィジェット右上の<img class="button-icon" src="../../assets/icons/widget-settings.svg" width="20" height="20" alt="歯車">（設定）をタップし、「保存」をタップします。改善しない場合はホーム画面から配置し直してください。

<a id="migration-missing-data"></a>

## 移行後に予定が見つからない

### データの復元を確認する

**原因：** Androidのバックアップ対象外のデータ、端末メーカーやOSが移行しなかったデータ、アカウント同期前の端末予定などが考えられます。

**確認方法：** Androidの復元が完了しているか、同じアカウントで端末カレンダーが同期されているか確認します。

**解決方法：** 端末カレンダーの権限と連携を再設定し、iCal購読を再同期します。詳しくは[バックアップと機種変更](10-backup-migration.md)をご覧ください。
