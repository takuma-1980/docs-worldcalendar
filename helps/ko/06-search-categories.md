# 제6장 검색과 카테고리

검색은 로컬 일정, 연결한 기기 캘린더와 구독에서 가져온 일정을 함께 찾습니다.

## 검색하기

주 화면의 ‘검색’을 누르고 검색어를 입력하세요. 한글 입력을 마치고 잠시 기다리면 결과가 갱신됩니다. 제목·설명·카테고리 이름·현재 표시 달력의 날짜가 검색 대상이며 장소나 출처 이름은 검색 대상이 아닙니다. 빈 검색어에는 결과가 표시되지 않습니다.

검색 기간은 현재 시점의 앞뒤 2년입니다. 결과는 일정 발생 시각의 최신순입니다. 반복 일정은 이 기간 안의 회차로 검색됩니다. 연결·구독 캘린더의 표시가 꺼져 있으면 결과에서 제외됩니다. 초성 검색이나 모든 유니코드 정규화 조합의 동등 검색을 보장하지 않습니다. 결과가 없으면 단어 일부와 날짜 범위를 바꾸어 확인하세요.

## 카테고리 관리

‘설정 → 일정 관리’의 로컬 항목에서 추가 버튼을 누르고 이름·색상을 정해 저장하세요. 카테고리는 최대 50개이며 최소 한 개는 남아 있어야 합니다. 수정 버튼으로 이름과 색상을 바꿀 수 있습니다.

카테고리를 삭제하면 일정과의 연결이 해제되지만 일정 자체는 삭제되지 않습니다. 삭제는 확인 화면 없이 적용되므로 주의하세요. 마지막 카테고리는 삭제할 수 없습니다. 카테고리 표시를 꺼도 검색에서 해당 일정이 제외되는 것은 아닙니다.

카테고리는 로컬 일정에만 지정할 수 있습니다. 기기 캘린더와 ICS 구독은 [저장 위치별 기능](04-events.md#event-save-target)을 확인하세요.
