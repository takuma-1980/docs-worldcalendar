# 제10장 백업과 기기 변경

Android의 자동 백업 또는 기기 간 전송을 사용합니다. 앱에 일괄 내보내기·가져오기 기능은 없습니다. OS·제조사·Google 계정·백업 설정에 따라 실행 여부가 달라지며 앱이 복원을 보장하지 않습니다.

## 포함될 수 있는 데이터

백업 대상은 로컬 일정, 미리 알림 설정, 반복 예외, 카테고리, 달력 설정, ICS 구독 등록 정보와 일부 사용자 설정입니다. 기기 동기화 사용 여부, 기기 캘린더 알림 설정, 테마와 달력 표시 설정도 일부 포함될 수 있습니다.

## 제외되는 데이터

기기 캘린더 연결 정보·권한·목록 선택, 내려받은 기기·ICS 일정, 동기화 상태, 기기별 알림 예약, 위젯 배치·표시 설정은 제외됩니다. 외부 계정의 원본 일정은 해당 서비스의 계정 동기화로 복원해야 합니다.

약관 동의 기록은 백업 대상 사용자 설정에 포함됩니다. 복원된 동의의 버전·언어·시각 등 유효성에 따라 앱이 다시 동의를 요구할 수 있습니다. 앱 언어와 OS 권한은 별도로 확인하고, 복원 후 앱이 안내하는 약관 절차를 따르세요. 백업 복원이 새 약관이나 별도 정보 처리 동의에 대한 승인을 뜻하지는 않습니다.

## 기기를 바꾸기 전과 후

1. 이전 기기의 Android 백업 설정과 마지막 완료 상태를 확인하세요. 로컬·기기·구독별로 중요한 일정을 확인합니다.
2. 새 기기에서 Android 복원을 마친 뒤 앱의 일정과 설정을 확인하세요.
3. 앱 언어를 확인하고 캘린더 읽기·쓰기 권한을 허용한 뒤 계정 연동을 다시 확인하세요.
4. 구독 등록 정보가 복원되었는지 확인하고 계정 연동을 활성화해 동기화하세요.
5. 알림 권한과 알림 예약 상태를 확인하고 홈 화면 위젯을 다시 배치하세요.

복원되지 않은 데이터가 있다면 앱 삭제나 데이터 초기화 전에 백업과 원본 계정 상태를 확인하세요. [문제 해결](11-troubleshooting.md#migration-missing-data)을 참고하세요.
