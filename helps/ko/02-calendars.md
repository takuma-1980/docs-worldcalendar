# 제2장 세계의 달력

달력은 날짜를 표시하는 체계입니다. 같은 순간도 달력과 시간대에 따라 날짜가 다를 수 있습니다.

## 일곱 가지 달력

| 달력 | 표시 방식 |
| --- | --- |
| 그레고리력 | 일반적으로 사용하는 양력 |
| 한국 음력 | 한국 음력 변환표를 사용하는 태음태양력 |
| 일본 구력 (태음태양력) | 일본의 구력 계산 방식에 따른 달력 |
| 율리우스력 | 그레고리력과 윤년 규칙이 다른 양력 |
| 히브리력 | 유대교 전통의 태음태양력 |
| 비크람력 (아만타) | 인도 태음태양력의 아만타 방식에 따른 앱 표시 |
| 에티오피아력 | 13개월로 구성된 달력 |

한국 음력과 일본 구력은 서로 다른 달력입니다. 일본 구력을 한국 음력의 대체 자료로 사용하지 마세요.

## 한국 음력의 범위와 윤달

한국 음력은 **양력 1900년 1월 1일~2050년 12월 31일**에 해당하는 변환표 범위를 지원합니다. 이것은 음력 연도의 모든 날짜를 보장하는 범위가 아닙니다. 양력 1900년 초에는 음력 1899년의 일부 날짜가 포함되며, 양력 2050년 말에도 음력 연도의 일부만 포함될 수 있습니다.

윤달은 ‘윤’으로 구분합니다. 같은 숫자의 평달과 윤달은 다른 달입니다. 범위 밖에는 지원 범위 안내가 표시되며 일본 구력으로 대신 계산하지 않습니다. 중요한 기념일과 공휴일은 해당 기관의 자료와도 대조하세요. 한국 음력 날짜 표시와 [대한민국 공휴일 구독](08-subscriptions.md)은 별도 기능입니다.

## 날짜가 바뀌는 기준

| 달력 | 날짜 표시 경계 |
| --- | --- |
| 그레고리력·율리우스력 | 기기 시간대의 자정 |
| 한국 음력 | Asia/Seoul의 자정 |
| 일본 구력 | 일본 시간의 자정 |
| 히브리력 | 예루살렘 시간의 자정, 일몰 기준 아님 |
| 비크람력 (아만타) | 인도 표준시의 자정, 종교력의 일출·티티와 다름 |
| 에티오피아력 | 아디스아바바 시간의 오전 6시 |

비크람력의 월 첫날은 인도 표준시에서 합삭이 일어나는 날짜로 정하며 날짜 숫자는 월 시작부터 센 일수입니다. 종교 의례용 티티와 다릅니다. 일본 구력에는 2033년의 월 이름 결정 문제처럼 방식에 따른 차이가 있습니다.

시간이 있는 일정의 입력 기준은 날짜 표시 경계와 다를 수 있습니다. 특히 에티오피아력에서 00:00 입력은 기기 시간대의 06:00에 대응합니다. 다른 시간대로 이동했을 때는 일정 상세의 날짜와 시각을 확인하세요.

## 달력 선택과 표시 설정

주 화면 왼쪽 위의 달력 이름을 눌러 활성화된 달력 중에서 선택하세요. ‘설정 → 달력 표시 설정’에서 표시 여부와 순서를 바꿀 수 있습니다. 순서 변경 손잡이를 길게 눌러 이동하고 색상 원을 눌러 색상을 바꾸세요. 최소 한 개는 활성화해야 합니다.

‘설정 → 일정 관리’의 로쿠요 표시 옵션은 그레고리력과 일본 구력에만 적용됩니다. 로쿠요는 한국 공휴일 정보가 아닙니다.
