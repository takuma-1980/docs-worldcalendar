# 제4장 일정 추가와 수정

일정의 저장 위치에 따라 사용할 수 있는 기능이 다릅니다.

<a id="event-save-target"></a>

## 저장 위치

| 저장 위치 | 주요 동작 |
| --- | --- |
| 로컬 | 앱 안에 저장. 카테고리, 반복과 미리 알림 사용 |
| 기기 캘린더 | 연결·권한·쓰기 가능 여부에 따라 생성·수정·삭제 |
| iCal 구독 | 읽기 전용. 원본 수정·삭제 불가, 별도 일정으로 복제 가능 |

<a id="event-add"></a>

## 일정 추가

1. 주 화면의 ‘일정 추가’를 누르세요.
2. 제목을 입력하고 저장 위치를 확인하세요. 한글 제목·장소·설명을 입력할 수 있습니다.
3. 필요에 따라 ‘하루 종일’, 시작·종료 날짜와 시각, 반복과 미리 알림을 설정하세요.
4. 로컬 일정은 카테고리를 선택할 수 있습니다. 내용을 확인하고 ‘저장’을 누르세요.

입력 달력의 날짜와 평달·윤달을 구분하세요. 시작보다 종료가 빠르지 않은지 확인합니다. 시간 선택과 표시는 24시간제를 사용합니다. 기기 캘린더가 저장 위치로 보이지 않으면 [연결과 권한](07-calendar-sync.md)을 확인하세요.

## 수정·복제·삭제

상세 화면의 ‘수정’에서 변경 후 저장합니다. 기존 일정의 저장 위치는 바꿀 수 없습니다. ‘복제’는 원본과 별개의 새 일정을 만들며, 처음에는 로컬 일정으로 열립니다. 저장 위치 선택이 가능하면 바꿀 수 있습니다.

‘삭제’는 확인 후 진행합니다. 반복 일정은 이번 일정만, 이번 이후, 과거를 포함한 전체 중 표시되는 범위를 확인하세요. 기기 캘린더에서는 일부 회차 삭제가 제공자에게 그대로 반영되지 않을 수 있으므로 원본 서비스에서도 확인하세요.

읽기 전용 일정에는 수정·삭제가 표시되지 않을 수 있습니다. 구독 원본은 제공자의 서비스에서 변경하세요.
