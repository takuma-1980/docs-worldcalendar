# 제11장 문제 해결

증상에 맞는 설정부터 확인하세요. 데이터 삭제나 앱 재설치는 백업과 원본 확인 후 결정하세요.

<a id="notification-missing"></a>

## 알림이 오지 않아요

앱 알림 권한, 알림 채널, 미리 알림 시점, 기기 절전·알람 제한을 확인하세요. 기기 캘린더는 계정 연동의 일정 알림 설정도 확인합니다. 구독 일정에는 미리 알림을 추가할 수 없습니다. 다른 앱에서 같은 일정 알림을 보내는지도 확인하세요.

<a id="device-calendar-missing"></a>

## 기기 캘린더가 보이지 않아요

Android에 계정과 캘린더가 등록되어 있는지, 읽기·쓰기 권한과 계정 연동이 활성화되어 있는지 확인하세요. 표시 체크와 쓰기 가능 여부를 확인하고 동기화 후 잠시 기다리세요.

<a id="ical-load-error"></a>

## ICS를 가져오지 못해요

네트워크와 HTTPS ICS 주소를 확인하세요. 로그인 페이지 주소와 캘린더 보기 주소는 사용할 수 없습니다. 이후 업데이트는 계정 연동이 필요합니다. 마지막 동기화 상태, 5분 수동 대기 시간과 24시간 자동 갱신 간격을 확인하세요. 공휴일 누락이 제공자 자료의 문제인지도 대조하세요.

<a id="language"></a>

## 이전 언어가 남아요

Android 13 이상에서는 앱 언어와 시스템 언어를 각각 확인하세요. 이전 OS는 시스템 언어를 확인합니다. 앱을 다시 열고 새로 발생하는 알림과 위젯을 따로 확인하세요. 이미 표시된 알림·채널 이름의 즉시 갱신은 기기에서 검증이 필요합니다. 사용자가 입력한 일정 제목과 외부 ICS 원문은 번역되지 않습니다.

<a id="widget-not-updated"></a>

## 위젯 표시가 갱신되지 않아요

앱과 위젯 설정을 열고 저장한 뒤 확인하세요. 홈 앱·절전 제한·위젯 크기를 확인합니다. 필요하면 위젯을 다시 배치하세요. 그래도 언어가 남거나 글자가 잘리면 OS, 홈 앱, 앱 언어와 글자 크기를 기록하세요.

<a id="migration-missing-data"></a>

## 복원 후 일정이 없어요

Android 백업 완료 여부와 계정을 확인하세요. 기기 일정은 원본 계정 연결을, 구독은 등록 정보와 다시 가져오기를 확인합니다. [백업 대상과 제외 데이터](10-backup-migration.md)를 확인하고 로컬 데이터가 보이지 않는 상태에서 초기화하지 마세요.

## 한국 음력과 공휴일이 달라요

한국 음력과 일본 구력을 구분하고 평달·윤달, 양력 기준 지원 범위와 시간대를 확인하세요. 공휴일은 별도 ICS입니다. 공휴일 원문과 공식 발표를 대조하세요. 달력 계산 문제와 ICS 자료 문제를 나누어 기록하면 확인에 도움이 됩니다.

## 문의와 법률 문서

한국어 문의 방식 B와 한국어 법률 문서는 승인 전 비공개 상태입니다. 이 문서에서는 한국어 초안의 공개 URL이나 발송 기능을 제공하지 않습니다. 현재 공개된 [문의 안내 (영어)](/en/contact/), [개인정보 처리방침 (영어)](/privacy-policy/en/), [이용약관 (영어)](/terms-of-use/en/)은 영어 페이지로 이동합니다.

문의에는 앱 버전·OS·언어·증상과 재현 순서만 필요한 범위에서 적으세요. 일정 전체, 계정 정보, 비밀 ICS URL과 불필요한 개인정보는 보내지 마세요. 영어 안내만으로 한국어 권리 행사 창구의 승인이 완료된 것은 아닙니다.
