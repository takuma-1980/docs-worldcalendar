# WorldCalendar 韓国公開 Phase 2 調査結果

調査日：2026-11-22（JST）。内部検討用。正式な法律意見・公開承認ではない。

## 1. 結論

**公開可否の暫定評価：法的判断に必要な情報が不足している。** 現構成のNPA広告を韓国で無条件に配信可能とも、韓国利用者全員に必ず独自同意画面が必要とも確定できない。未確定なのは単なる条文検索ではなく、SDK処理の法的主体、Googleの独自利用、実受領者・処理国・保持期間と、それに適用する根拠である。

- NPAは広告選択のパーソナライズを抑える設定であり、個人情報処理をなくさない。[Google NPA説明](https://support.google.com/admob/answer/7676680?hl=en)
- 韓国の国外移転は別個同意のほか一定の根拠を認めるが、契約履行による公表ルートは**必要な処理委託・保管**に限定される。通常AdMobをそのまま委託とする証拠はない。[PIPA 28条の8](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029334869)
- 海外事業者の直接収集は移転と異なる。ただしSDKの直送だけでWorldCalendarが提供・委託していないとは判定できない。[PIPCの直接収集解説](https://pipc.go.kr/np/cop/bbs/selectBoardArticle.do?bbsId=BS292&mCode=C050010000&nttId=10972)
- 問い合わせ方式Bは維持する。現行日英説明の「日本国外」だけでは韓国向けの移転国・根拠等を満たすと評価できない。法定代理人確認も実装されていない。
- 一般向け暦アプリであることと14歳未満の個人情報を処理する場合の義務は別。2026-11-23に韓国対象は満16歳以上と決定。Playは「16～17歳」「18歳以上」を選択予定（未操作）。この方針だけで14歳未満の情報処理に関する義務が消滅するわけではない。

## 3. 必須対応と推奨対応

| 区分 | 対応 | 判断根拠・完了条件 |
|---|---|---|
| 韓国公開前に必須 | 残る処理の主体・法的根拠を経路ごとに確定 | PIPA 15・17・26・28条の8。Googleから事実を取得し、契約と実装を法務判断に照合。未確定のまま広告配信を許可しないという公開管理条件 |
| 韓国公開前に必須 | 韓国利用者が理解できる処理方針と権利窓口を用意 | 30条・施行令31条。Phase 3要件表の必須欄を確定し、未確認の国・保持期間を架空値で埋めない |
| 韓国公開前に必須 | 問い合わせの保存根拠を再評価 | 21条。既存の完了後1年・最長1年1か月を韓国の全問い合わせへそのまま適用しない |
| 条件次第で必須 | 広告の目的別同意、国外移転の別個同意と初期化前ゲート | 15・17・22・28条の8に基づく同意ルートを採る場合。他の根拠が具体的に成立すれば画面不要の余地あり |
| 条件次第で必須 | 14歳未満の法定代理人同意・確認 | 22条の2。法律上同意が必要な処理を子どもに実行する場合 |
| 条件次第で必須 | 国内代理人、利用内訳通知、漏えい通知・届出等 | 規模・処理・事故条件で判定。個人開発という理由で免除としない |
| 推奨 | 不明な地域・年齢では広告を開始しない設計を検討 | 不足する根拠を誤って許可扱いしないための実装上の提案。韓国法が地域選択UI自体を一律に要求するとの判断ではない |
| 推奨 | 保存国・用途・SDK版ごとの確認履歴を定期点検 | 契約・広告ソース・法令変更時の再評価に用いる |
| 対応不要と判断できるもの | 全体停止を維持するAnalyticsの新規収集同意UI | 今回のPhase 1完了前提に限る。過去データの保持・権利対応は残る |
| 対応不要と判断できるもの | UMPの一律導入、完了済みPlay申告の再提出 | 韓国法の専用同意をUMPだけで証明できない。新たに処理・対象年齢・任意性が変わる場合のみ申告差分を引き継ぐ |

## 4. Android改修要求

現時点では法令上必須の独自同意画面を確定しない。同意ルートが必要と判明した場合、`WorldCalendarApplication.onCreate()`、`AdMobBanner`、`AdMobNativeAd`、`AdRequestFactory`、設定画面を改修対象とする。初期化順序、端末内の同意状態、復元時の無効化、拒否・撤回時の広告停止と試験条件は [T07](T07-consent-notice.md) に定義した。今回はコード変更なし。

## 5. Phase 3への引き継ぎ

韓国語ポリシーの章別要件は [T05-KR](T05-KR-research.md) の要件表を使う。受領法人・連絡先、実処理国、保持期間、委託／第三者提供の分類、拒否時の影響、権利行使の期限、責任者情報を確定する必要がある。年齢方針は満16歳以上に確定済みで、対象外利用・年齢不明時の運用は残る。

利用規約には、一般向け機能、連携先とOSによる処理、バックアップ・ICSの限界、未成年者の利用契約、変更告知、韓国の強行的消費者保護との整合を引き継ぐ。利用規約の受諾を広告・第三者提供・国外移転の同意に代用しない。準拠法・免責・裁判管轄・未成年契約の韓国法上の効力は未確認で、Phase 3で韓国の約款・民法等の確認を別途行う。今回完成文は作らない。
