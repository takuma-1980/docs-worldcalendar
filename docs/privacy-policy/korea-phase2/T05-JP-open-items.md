# T05-JP 日本法上の残存課題

調査日：2026-11-22（JST）。状態：一部調査済み。既存[T05-JP整理](../2026-11-22-legal-review-questions.md)、[方式B運用](../2026-11-22-inquiry-options.md)、[契約調査](../2026-11-21-contract-review.md)を再利用し、未解決の事項だけを抽出する。過去のAnalytics標準収集維持・Play申告未完了の記載は今回の前提に用いない。

| 残存ID | 現在の根拠と判断限界 | 確認方法・完了条件 |
|---|---|---|
| JP-01 開発者側の分類 | 独自アカウント・User-ID対応付け・予定本文の開発者サーバー送信は調査範囲で未検出。SDK識別子は個人関連情報候補だが、容易照合性・個人関連情報データベース等の事業該当性を未確定。問い合わせは本人と結び付く別経路 | 生データへのアクセス権、Consoleの閲覧粒度、SDKでの提供主体を確認し、法2条・16条等の該当性を経路別に記録 |
| JP-02 Google側での個人データ取得 | Google APPI案内は関連付けと同意取得を説明する。NPA・PII送信禁止だけでは関連付け不可を証明できない | AdMobの実契約・受領主体・利用目的にGoogle案内が適用される範囲を確認し、版と確認日を保管 |
| JP-03 法31条 | 受領者で個人データとして取得すると想定される等の条件次第。すべての識別子送信に一律適用ではない | JP-01・02とPPC資料を照合し、確認義務・本人への情報提供・記録の項目、起算点・保存期間を確定。Googleの公表を確認根拠に使える範囲を評価 |
| JP-04 外国提供 | AdMob契約先はGAP、問い合わせ無料GoogleサービスはGoogle LLCとの既存確認。法人国と全処理国は別 | 法28条又は31条の各経路、基準適合体制の適用、相当措置・継続確認・求めに応じた情報提供を実契約に照合。広告向け説明を無料メールへ流用しない |
| JP-05 外部送信規律 | 暦計算・ローカル予定管理だけでは対象役務と確定しない。ICS公開情報の閲覧提供、同期機能の提供主体等が未確定 | 不特定利用者向けの提供実態・通信媒介・閲覧役務を画面と経路図で総務省又は専門家に照合。該当時は送信項目、宛先、双方の目的、アプリからの容易な到達を確認 |
| JP-06 NPAの実効性 | 3要求が`npa=1`を経由するソースは再確認済み。初期化通信、広告購入者、実保持・関連付けは未確認 | GMA25.4.0の実処理と広告ソースを照合。AAID・App Set ID・IP等が残ることを前提にJP-01～04を判断 |
| JP-07 方式Bの証跡 | チェック状態・選択日時なし。受信本文の同意文・説明版は証拠候補だが事前表示・本人性・能力・代理人関与を完全には証明しない | 説明版履歴、受信本文・受信日時、編集／欠落時の確認記録を限定保持。法定第三者提供等の記録義務が該当すれば現1年・最長1年1か月との整合を確認 |
| JP-08 直接メール・未成年・権利請求 | Bを経由せず受信する経路が残る。受信後の意思確認は受信前の根拠を修復しない | 無同意で必要な処理の根拠、追加転送停止、必要時の代理人、権利請求を包括同意で塞がない運用を確定。方式Aへ変更しない |
| JP-09 過去Analytics | 新規停止は送信済みデータの削除ではない。GA4の設定・契約・依頼者照合不可の既存事実が残る | 必要な破棄、保存・権利対応、適用契約を旧データに限って確認。新規収集の同意画面を理由なく追加しない |

根拠：[PPC法31条FAQ](https://www.ppc.go.jp/all_faq_index/faq1-q8-3/)、[Google APPI](https://business.safety.google/intl/ja/appi/)、[PPC外国提供編](https://www.ppc.go.jp/personalinfo/legal/guidelines_offshore/)、[共同ガイドライン解説](https://www.ppc.go.jp/files/pdf/250601_telecom_GLs_description.pdf)、[Google NPA](https://support.google.com/admob/answer/7676680?hl=ja)。PPC FAQとGoogle APPIは今回再確認。他の日本法資料の調査内容は既存資料を参照し、現行改正全体を再監査したとはしない。

**日本向けAdMob専用同意画面を追加しない方針を維持する。** 今回、日本向けに追加同意必須と新たに確定した処理はない。一方で同意不要を確定したわけでもなく、上記確認で必要と判明した場合は方針との衝突を未解決事項として報告する。韓国法の同意条件から日本法の結論を逆算しない。
