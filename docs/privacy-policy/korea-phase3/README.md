## 章構成・日本語版との差分

処理方針は15章：提供者、項目と目的、AdMob、第三者提供、委託、国外処理、Provider、ICS、OS、保持破棄、旧Analytics、権利、児童、安全管理／責任者、変更施行。日英の9章を経路と法的区分で分け、権利の10日期限、14歳未満、過去Analyticsを補った。日英の記載が省略しているものを実態なしと解釈しない。保持国・期間を仮値で埋めていないため、公開文としては未完成。

規約は12条：適用、機能、条件と未成年、禁止と権利、暦精度、データ管理、外部連携／通知／広告、責任、サービス変更、約款変更、準拠法／管轄、問い合わせ。機能上の注意と法的責任の留保を維持し、日本民法548条の4の変更条項を韓国へ転用せず、沈黙による一律同意を避けた。現行日本語版も特定の準拠法・専属管轄を指定していないため、誤って「日本法条項を削除した」とは報告しない。韓国旧暦と韓国祝日は未配布候補ソースの差分として記載した。

問い合わせは日本国外という基準を韓国外処理へ変更し、日本所在開発者とGoogleを区別。日英の1年保存を韓国へ確定適用しない。受信メールで意思表示・版を確認する方式Bを維持するが、現草案は操作も送信もできない。収集利用・提供同意も必要となれば別の選択欄が必要で、現移転チェックだけで充足としない。

## 非公開制御と引き継ぎ

`_config.yml` の既存 `exclude: docs` に依拠する。`published: false`は補助で、`draft: true`には依存しない。独自プラグインのdraft除外はnews/calendarsコレクション向けであり、一般ページへの万能な公開制御ではない。全草案はdocs内に置き、実URLのpermalinkやkoのナビ・hreflang・サイトマップ登録を追加しない。問い合わせはnoindexだけで守らず、静的HTMLとしても全チェック／ボタン無効、JS・mailto・宛先data属性なしとする。

問い合わせは既存CSSと既存JSが要求するdata属性・テンプレート形式を再利用。現時点ではJSを読み込まない。承認後に `_data/inquiry.yml` のko値とincludeの説明版を別作業で整備し、必要な同意区分を維持して `assets/inquiry-consent.js` を接続する。既存JSは一つのチェックを前提とするため、同意区分追加時にはゲートの改修・試験が必要。今は既存include、データ、CSS、JSのいずれも変更しない。

次はopen-itemsの証拠回収・法的判定、確定した16歳以上方針の設定照合・対象外利用対応、保持と韓国語権利運用、最終アプリ機能・文書版との一致を完了させる。その後必要な同意UIを別タスクで実装・試験し、正式な文書校正と公開承認を経てURLへ移す。今回の草案はPlay用公開URLとして案内しない。
